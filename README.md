# Pavel Fryblik — personal portfolio

A bilingual, responsive static portfolio for GitHub Pages.

## Deploy to GitHub Pages
1. Create a repository, e.g. `pavel-fryblik-portfolio`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

The site is plain HTML, CSS and JavaScript. No build step is required.

## Before publishing
- Check that the CV PDF in `assets/` is the version you want public.
- Confirm the excerpts from LinkedIn recommendations can be republished with names.
- Check the English and Czech wording and any details you want to keep private.
- The contact email and LinkedIn profile are currently included.
